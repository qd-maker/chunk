# 素材库

素材库是一个 JSON 文件，列出你想练的句式、衔接表达和按话题分组的词块。程序第一次启动、数据库还是空的时候，把它导入成「库」里的表达。

仓库只带一份示例：`examples/library.example.json`，12 条句式、6 条衔接表达、3 个话题，句子都是为这个项目写的。

## 放在哪

放在数据目录里，文件名 `library.json`：

| 场景 | 数据目录 | 素材文件 |
|------|----------|----------|
| 本地运行（`start.bat`） | `data/` | `data/library.json` |
| 演示（`scripts/run_demo.py`） | `data-demo/` | 没有就自动复制示例 |
| Docker | 容器里的 `/data`，挂载自 `./server-data` | `server-data/library.json` |

数据目录可以用环境变量 `DATA_DIR` 改。程序先找 `library.json`，找不到再找 `guide.json`（老版本的文件名，仍然认）。

## 结构

```json
{
  "patterns": [ ... ],
  "links": [ ... ],
  "topics": [ ... ]
}
```

### patterns：句式

一句完整的英文，里面有一个能反复套用的骨架。

| 字段 | 含义 |
|------|------|
| `no` | 编号，整数，在 patterns 里唯一 |
| `text` | 英文原句 |
| `zh` | 原句的中文 |
| `example` | 同一个骨架换了内容的另一句 |
| `example_zh` | 例句的中文 |
| `first_batch` | `true` 表示推荐先练，库里可以只看这些 |

### links：衔接表达

用来把话接下去的表达，比如举例、补充、转折。

| 字段 | 含义 |
|------|------|
| `no` | 编号，在 links 里唯一 |
| `cat` | 中文分类名，库里按它分组 |
| `text` / `zh` | 英文句子和中文 |
| `example` / `example_zh` | 另一句例句和中文 |
| `usage` | 一句中文，说什么时候用 |

### topics：话题

| 字段 | 含义 |
|------|------|
| `no` | 话题编号 |
| `group` | 分组字母，`A` 生活型、`B` 经历型、`C` 观点型 |
| `zh` / `en` | 话题名 |
| `chunks` | 词块：`text` 是不带主语的短语（如 `catch up on sleep`），`zh` 是中文 |
| `patterns` | 这个话题里常说的整句：`text`、`zh` |
| `questions` | 这个话题的聊天问题：`text`、`zh`。目前不导入，留着自己看 |

## 条目 id

导入时按编号生成 id，`NN` 补成两位：

| 来源 | id | 例子 |
|------|----|------|
| 句式 | `IV-NN` | `IV-09` |
| 衔接表达 | `V-NN` | `V-02` |
| 话题词块 | `VI-NN-cK`（K 是在该话题里的序号，从 1 开始） | `VI-01-c2` |
| 话题句式 | `VI-NN-pK` | `VI-03-p1` |

练习记录按 id 关联。同一个 id 已经存在就跳过，不覆盖。

## 换成自己的素材

1. 照上面的结构写一个 JSON，存成数据目录里的 `library.json`。
2. 如果数据目录里已经有 `chunk.db`，先把它挪走（或删掉）。
3. 启动程序，库里就是你的素材了。

可以先拿示例文件改：`cp examples/library.example.json data/library.json`。

## 已经练了一阵再改素材

素材只在数据库为空时导入一次。之后再改 `library.json`，已有的数据库不会变：

- 新加的条目不会出现。
- 改了文字的条目还是旧文字。
- 删掉的条目还在库里。

想用新素材，只能换一个空的数据目录重新开始，或者删掉 `chunk.db`（练习记录会一起没了）。删之前先备份。

自己练习时收进来的纠错和自定义表达存在数据库里，不在素材文件里。
